# Women Safety Analysis - Tamil Nadu

A Python project that analyzes crimes against women in Tamil Nadu districts.

## What it does
- Analyzes district-wise crime data
- Classifies areas as Low / Medium / High Danger
- Visualizes top dangerous districts
- Predicts future crime count using Random Forest

## Tools Used
Python, Pandas, Matplotlib, Scikit-learn

## Dataset Columns
Year, District, Area, Crime_Type, Victim_Age, Time, Urban_Rural, Police_Station, Crime_Count
